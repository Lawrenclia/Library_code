# 0.1.7：WOS 站点故障保留队列位置

本版包含 0.1.6 的 Excel A 列空白筛选，升级后重新导入名单，详见 [名单规则](TAURI_TESTING_0_1_6.md)。

WOS 返回 Cloudflare 524 等明确的 5xx 错误页时，页面适配器在检索或导出控件操作前识别错误，返回独立的站点故障代码。故障页与普通文献中的 Cloudflare 文本分开判断，以错误页容器或错误标题和错误码共同识别。

错误页或页面切换也可能导致程序收不到回执。短暂的只读探针超时仍在原等待期限内继续观察；页面准备、表单准备、结果等待和导出准备到达最终期限后，视为 WOS 通道暂不可用，队列停在当前论文，不消耗当前位置，不触碰剩余任务。明确的数据库零结果和普通单篇问题仍逐篇推进，没有恢复连续三条失败终止规则。

已经发出的原生下载继续遵循回执核验：结果未知不重新导出，队列暂停，保留原下载请求与文件路径。页面服务故障不产生“未收录”或“已下载”的结论。恢复站点后由用户继续原队列；不会在服务器错误页上自动刷新或重新搜索。

用户自测建议：遇到真实 524 页面时核对站点故障提示、队列当前位置和后续论文均保留；站点恢复后继续原范围；用明确零结果核对仍会处理下一篇；重启后核对原进度和下载回执保留。等待上限不是 WOS 服务恢复承诺。本轮只编译打包，未运行测试或操作真实网站，暂停恢复与防重复提交仍待用户现场验收。
