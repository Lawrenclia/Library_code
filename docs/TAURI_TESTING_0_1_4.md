# 0.1.4 自测说明

本版接入 CNKI Excel 在应用内另存为 XLSX，保留 0.1.3 的浏览器题录获取与已有工作台功能。只编译打包，未运行测试、安装启动或操作真实网站。

1. 在 [Windows EXE](https://github.com/Lawrenclia/Library_code/actions/workflows/windows-exe.yml) 点击 **Run workflow**，保持工作流分支及 `source_ref` 为 **main**。编译成功后下载 **Artifacts** 中的 ZIP，解压安装 EXE；应用显示 **v0.1.4 测试版**。
2. 选择论文，在“来源”选择 CNKI，在内置窗口自行登录、检索并导出 Excel。实际下载仍保存到工作目录 `downloads/sources`。
3. 对完成的 Excel 下载点击 **另存为 XLSX 并选择论文记录**；已有本地下载则点击 **选择 CNKI Excel 并另存为 XLSX**。网页表格格式的 XLS 也走此入口。
4. 预览显示原件与另存文件位置。核对全部关键字段、正确表头、题名/DOI 列和实际记录，填写来源与绑定依据后确认。若 GBK 网页导出无法解码，选择 **GB18030 / GBK** 后重新读取。
5. 绑定后可以调用 API AI 分类及填写已登记模板；必要字段缺失仍需来源。提交资料包包含完整原下载、另存回执及选定材料，供后续渠道核对。

包含公式、日期/错误类型、HTML 合并或嵌套表格、非文本内容及超过限制的字段时，自动另存会提示人工处理；原件保留。另存不会确认身份、交大归属、本库缺失或平台成功，也不会自动截取选中一行作为上传文件。

CNKI 自动上传、导入和推送仍未接通；WOS TXT 保留现有独立流程。实际业务和恢复效果由用户自测，失败时保留错误、原文件和源码版本。
