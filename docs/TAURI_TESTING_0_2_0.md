# 0.2.0 使用与自测说明

当前版本新增各渠道共用的来源驱动、批量获取和原始导出恢复，统一 Excel 另存入口与来源报告。它包含此前 PPT 分流、WOS/CNKI 专用获取、AI/模板材料及平台操作链路。源码版本和包哈希见 [交付记录](TAURI_ACCEPTANCE_STATUS.md)。

本轮仅编译打包，未执行测试、未启动应用或操作真实网站；下列操作供用户自测，不表示已经通过。

## 起步

导入名单，确认只出现物理 A 列空白行，选择负责人。在“模型与设置”查看真实工作目录、配置 API 地址/模型/密钥，注册实际平台模板。在内置 WOS 和机构库窗口完成登录，确认后台访问权限。

先选一篇可核对的论文，取得来源并检查保存文件，再启动批量任务。原来已保存的记录、原件及检查点继续保留；不要通过删除工作目录规避未知状态。

## WOS

在 WOS 专用入口使用核心合集检索、核对唯一目标、导出完整记录制表符 TXT。原生下载完成后选择论文并核对身份。来源报告应保留原始文件、实际 URL、哈希和 SA 归属。

逐篇没有记录会继续其他任务。524、登录、页面故障或未知下载暂停通道；恢复页面后继续原范围，没有连续三次失败终止逻辑。524 是来源服务器超时，不是论文缺失。

## CNKI 及其他数据库

1. 在“来源”选择渠道，保存真实检索入口和允许的下载域名。入口或页面格式改变后，先核对已有窗口是否仍对应当前配置。
2. CNKI 可以使用专用自动检索和题录获取；其他渠道可使用“自动检索并获取来源”，共用驱动依次核对完整结果、唯一题名、详情和原导出。
3. 页面控件无法唯一识别时，展开“渠道流程”，保存当前页面的实际定位条件。检索地址支持 `{title}` 和 `{doi}`，必须保持在保存的渠道域名内。
4. 可配置检索输入框、按钮、结果行、题名链接、总结果数、零结果控件和详情题名；导出步骤为 `click`、`select`、`check`，每一步需实际选择器和精确显示文字，不填写 JavaScript。
5. 默认识别失败时打开已核对的单篇详情，点击保存当前详情来源；题名纠正时需实际 DOI 与名单 DOI 一致。未核实身份不能靠手动入口绕过。
6. 取得原始下载后点击“选择论文记录”，明确表、表头、题名/DOI/WOS 列及本篇行。网页 XLS 或需要另存的 Excel 可选择“另存为 XLSX”，保留原件及转换回执。
7. 原始导出没有可确认结果时，程序保留完整详情来源和重要缺项。选择来源记录并填写核对依据后，可以调用 AI 整理实际模板；派生来源不会直接当成原格式上传。

重要字段包括作者、单位、年份、出版物、页码或文献号、DOI、摘要、关键词及作者角色。缺项表示需核对是否存在，不要求编造不适用字段。全部未知字段、重复字段、原始文本与响应仍保存在来源归档中。

## 批量来源与异常恢复

“获取当前负责人全部未处理论文的来源”固定本轮负责人、原名单、顺序、渠道和流程。普通单篇无记录或无法唯一选篇记录原因后继续；登录、通道超时、524、未知导出等保留当前位置并暂停。

可请求完成当前篇后暂停，继续原范围，或在暂停后结束原范围。重启时队列记录为中断，不自动恢复发出请求。更换名单或流程时，旧队列不能混入新记录；结束旧范围后建立新队列。

已完成文件按原回执和真实哈希复用。未知原导出先点击“核对原下载结果”；同一原会话有多份完成文件时选择实际文件。重新打开保存的详情来源可以继续整理，不重新请求网站。

确认原导出未完成后，先关闭原会话全部窗口，再核对实际下载并填写至少六个字的取消依据。已完成文件应先采纳，程序保留原件、历史和业务阶段，不删除资料。

## AI 与材料

注册真实平台模板，设置实际表头和字段规则。单篇或按负责人批量调用 API AI；每个建议字段必须引用有效来源，依据不足保持低置信度和缺项。

优先选择已核验的数据库原件；没有可用原始导出时使用实际模板。点击单篇或批量整理，核对材料与 `来源.json`。日期、枚举、必填和其他规则失败时保留草稿，不自动替换来源或把草稿当成可提交材料。

## 机构库流程

匹配 0 按四分支查本库；匹配 1 按原因核验；匹配 2 及以上明确主条目后核对合并。平台写入均经本条确认，上传、导入、推送分别回读；不能仅凭弹窗或按钮点击记为成功。

推送完成后关联实际平台条目，按完整工号选择作者、认领；需要别名时依据原文署名新增。逐原因核验完成后再确认 SA 处理。未查询到文献仅保存备注并回读，保持未处理。

写入结果未知先回读原操作，勿重新上传或推送。已经上传的原文件不会因重新分类、修改材料选择或更换名单而变为新的上传意图。

## 报告与反馈

导出“材料与来源”Excel，核对“任务与来源”“原始来源依据”“AI 字段来源”“渠道获取记录”“来源批量队列”等页。报告保存全部历史来源队列与获取记录，长内容按编号和分段号可重建。

遇到问题时保留：版本与源码提交、渠道、SA ID、操作步骤、完整错误、相关原生下载回执及报告。API 密钥不随反馈发送。未出现原生完成文件或业务回读时保留未知状态。
