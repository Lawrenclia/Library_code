## 来源驱动的具体边界

- WOS TXT 与 CNKI 使用专用获取逻辑，其他渠道使用共用且可配置的实际控件驱动。
- 通用驱动不是各网站私有 API 的硬编码实现；默认语义控件不唯一或结果范围不完整时，要求保存实际定位条件，或打开已核对的单篇详情。
- 自动选篇仅接受完整范围中的唯一精确题名。手动详情获取允许题名纠正，但必须有相同的实际 DOI；不同 DOI、没有可验证身份或同名歧义保留待核验。
- 导出点击前保存原始检查点；原生事件确认文件完成后才标记成功。未知检查点可核对同一原会话的完成文件，多份文件必须明确选择。
- 原生下载优先；页面详情与题录响应保留全字段供 AI/模板，不能当作原格式直接上传。超出完整采集边界时明确停止，不静默截取。
- 原件和另存转换都可追溯；无法完整保留的 Excel 停止转换。派生 RIS/JSON 不声明为原始数据库文件。
- Scopus 和其他来源无已证实的专用机构库按钮，通过实际平台模板整理；已有十个导入渠道使用各自格式和页面运行时约束。
