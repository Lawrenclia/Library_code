# CNKI 内置浏览器获取题录（0.1.3）

在本篇的「原始来源」中选择 CNKI，点击「按名单题名打开 CNKI」。首次使用自动登记官方入口，独立浏览器会话保存在工作目录的 `browser/source-cnki-profile`。登录、机构访问和验证码由用户在窗口完成。

默认搜索把完整题名作为关键词（`kw`，默认 `SU`），不是精确 Title 字段检索。用户核对结果并打开目标论文详情；程序不会选择首条，不会把无响应当作无记录。

## 两种获取方式

1. **网页原始导出**：在内置窗口导出 Excel/TXT。原生下载请求与完成事件写入本篇下载记录，文件直接保存在工作目录 `downloads/sources`，不进入系统 Downloads。完成后选择文件中的论文记录并确认绑定。接受 CNKI TXT、XLSX 和二进制 XLS；网页表格伪装的 XLS 需要用 Excel 打开并另存为 XLSX，原下载保留。
2. **获取当前详情页题录**：详情页公开的 `#export-url` / `#export-id` 提供同源 GetExport。程序利用当前内置会话获取 EndNote 标记题录，核对单篇题名及已有 DOI，再保存完整响应 JSON 到 `source-responses`、整理用 TXT 到 `downloads/sources`。TXT 内附完整响应与来源快照，归档按 SHA-256 校验。这是题录响应获取，不伪造原生下载完成事件。

第二种 TXT 是整理与填表的来源，不作为机构库原始上传文件候选。需要直接导入时使用第一种网页导出；获取的题录也可供 API AI 分类及填写已登记模板。平台 CNKI 自动上传、导入、推送仍未接通，不能复用 WOS 上传逻辑。

## 字段与确认

EndNote `%0` 和 RefWorks `RT` 格式按论文分行；保留未知标签、重复作者、多行摘要、空字段及完整原文。自动推荐题名/DOI 列，仍须明确选择记录并填写绑定依据。缺少作者、单位、年份或摘要时显示缺项；不替代作者身份、交大归属、本库查缺或人工审核。

网页不支持、登录验证、跨域代理、多篇返回、题名冲突、超时均返回具体错误，不自动重试、不假造成功；可继续在内置网页手动原始导出。机构代理入口可以另行保存，自动 GetExport 仅支持官方 HTTPS 同源页面。

协议依据：[CNKI translator 的当前公开实现](https://github.com/l0o0/translators_CN/blob/master/CNKI.js)，参考公开字段与协议，未复制其实现代码。

本版本只编译打包，未运行新增单元测试、未操作真实 CNKI/机构库。真实站点适配由用户自测。
