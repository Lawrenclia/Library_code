# 0.1.6：名单只处理 A 列为空的行

Excel 第一列按物理 A 列判断，与表头名称无关。A 列有“已处理”“跳过”、数字 1、2、0、其他文字或布尔值的行都跳过。空单元格、空字符串及只有空白字符的内容视为空。其他列出现“已处理”不替代 A 列筛选，平台状态仍沿用原有核验流程。

筛选发生在行数据校验之前：被跳过行的缺失编号、重复编号和匹配数量错误不阻止读取空白行。保留实际 Excel 行号；匹配数量仍负责后续业务分流，不参与 A 列筛选。全表均被跳过时允许载入 0 条任务。

升级安装后请重新导入原名单，才能为已有工作目录建立新的范围。重新导入只显示和处理此次 A 列为空的记录；之前导入、后来在 A 列填写内容的任务保留在数据库中，旧队列、单条操作与“重试跳过项”不能绕过新范围。原 Excel 完整归档，不删除已处理行，也不替用户设置平台已处理状态。若已有旧队列，先结束旧队列，再根据新的名单范围建立队列；原有下载及待确认操作记录保留。

建议自行核对：混合空白与多种状态的名单、A 列全非空、首个有内容的表头从 B/C 列开始、重新导入后旧记录被排除。这些是用户自测步骤，本轮按要求只编译打包，未运行测试或操作真实网站。
